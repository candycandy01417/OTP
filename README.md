# ワンタイムコード自動入力デモ（iPhone）

`autocomplete="one-time-code"` を付けた入力欄に、iPhoneがSMSやメールで届いた認証コードを候補として出す様子を確かめるためのデモページです。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | デモページ本体（HTML・CSS・JavaScriptを1ファイルに収録） |
| `.nojekyll` | GitHub PagesでJekyllの変換を行わず、ファイルをそのまま配信するための空ファイル |
| `README.md` | このファイル |

## 公開手順（GitHub Pages）

1. 個人アカウントでパブリックリポジトリを作る（例：`otp-demo`）
2. このフォルダのファイルをすべてリポジトリのルートに置いてコミットする
3. Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存する
4. 数分後、`https://ユーザー名.github.io/otp-demo/` で公開される

公開後、iPhoneのSafariで開き、「このページの環境」のドメインが `ユーザー名.github.io`、HTTPSが「はい」になっていることを確認する。

## デモの流れ

### パターンA：書式なし（メールで送る）

1. iPhoneのSafariでデモページを開いておく
2. Macから、iPhoneの標準メールアプリで受信しているアドレス宛てにメールを送る
   - 件名：認証コードのお知らせ
   - 本文：ページの「A. 書式なし」の文面
3. iPhoneで入力欄をタップし、キーボード上の「メールから」の候補をタップする
4. 入力欄にコードが入り、イベントログに記録されることを確認する

### パターンB・C：書式付き（SMSで送ってもらう）

1. iPhoneのSafariでデモページを開いておく
2. 別の人の端末から、ページの「B」または「C」の文面をSMSで送ってもらう
3. Bは候補が出る、Cは候補が出ないことを確認する

## 録画の構成

- iPhoneをUSBでMacに繋ぎ、QuickTime Playerの「新規ムービー収録」でカメラにiPhoneを選んで画面を映す
- 送信側のウィンドウ（メール作成画面）を横に並べる
- `Command + Shift + 5` でMacの画面全体を収録する

## 注意点

- 受信アドレスはiCloudメールがおすすめ。Gmailアカウントを標準メールアプリで使うと、すぐに届かないことがある
- iPhoneからiPhoneに送るとiMessageになる。B・Cは対象がSMSなので、Androidから送ってもらうか、送信側でiMessageをオフにしてSMSとして送る
- 録画前に集中モードをオンにして、関係ない通知が映り込まないようにする
- 送信者欄の電話番号や名前が映り込んでいないか、流す前に動画を確認する
- 文面や送り方によっては、iOSがコードと判定しないことがある。その場合は文面を実際のサービスに近づけて再度試す
